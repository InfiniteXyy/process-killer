# React Template Lite

## Main Stack

- Framework: `React 18` `NextJS` `TypeScript`
- CSS: `TailwindCSS` with `tailwind-iconify`
- Lint & Format: `ESLint` + `Prettier`
- DX: `unplugin-auto-imports`
